# Claude runtime workflow references

These project-local documents illustrate tasks using **ADK** capabilities.
They are not a second Skill catalog, router or permission framework.

- `feature-flow.md`: requirements, bounded implementation and verification.
- `bugfix-flow.md`: reproducible diagnosis, repair and regression.
- `refactor-flow.md`: behavior preservation and small reversible changes.

Select the single most relevant ADK Skill in the native runtime; other Skills are
supporting references, not mandatory consecutive invocations.
