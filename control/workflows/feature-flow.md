# Feature — ADK workflow map

1. Establish requirements and acceptance criteria with `adk-requirements-triage`.
2. For nontrivial changes select `adk-lightweight-planning` or `adk-task-breakdown`.
3. Implement in bounded changes; use `adk-parallel-agent-governance` for truly independent work.
4. Apply project-specific tests, review, and `adk-verification-before-completion`.
5. Close out with `adk-branch-closeout` only when SCM changes are in scope.

No globally injected procedure or third-party orchestration framework is required.
